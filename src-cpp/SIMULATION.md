# SITL Airbrake Simulation

This simulation models the rocket's ascent and airbrake control logic using a C++ program. It simulates the physics of flight, the airbrake drag, and the PID controller response.

## Files

- `sitl_main.cpp`: The main entry point for the **Software-In-The-Loop (SITL)** simulation.
- `hitl_main.cpp`: The main entry point for the **Hardware-In-The-Loop (HITL)** setup.
- `physics_engine.cpp` / `physics_engine.h`: Implements the 1D flight physics (drag, gravity, atmosphere).
- `pid_controller.cpp` / `pid_controller.h`: The PID control logic for the airbrakes.
- `plot_log.py`: A Python script to visualize the simulation results.
- `Makefile`: Build configuration for compiling the simulation.
- `sitl_flight_log.csv`: The output data file generated by the simulation.

## Setup

1. **Install Python Dependencies**
   The simulation uses Python to plot results automatically. 
   
   Create and set up the virtual environment (recommended):
   ```bash
   # Navigate to this directory
   cd src/devices/ESP32/data

   # Create a virtual environment named .venv (REQUIRED for main.cpp to find it)
   python3 -m venv .venv

   # Activate and install requirements
   source .venv/bin/activate
   pip install -r requirements.txt
   ```

2. **Compile the Simulation**
   This project includes a `Makefile` for easy compilation.

   To build the SITL simulation:
   ```bash
   make sitl
   ```
   
   This will generate an executable named `sitl_sim`.

## Running the Simulation

Run the compiled executable:

```bash
./sitl_sim
```

The program will:
1. Run the flight simulation from the configured initial conditions.
2. Log data to `sitl_flight_log.csv`.
3. Print flight status to the console.
4. Automatically execute `plot_log.py` using the `.venv` environment to generate visualization plots.

## Output

- **Console:** Final apogee, error from target, and simulation status.
- **sitl_flight_log.csv:** Time-series data of altitude, velocity, predicted apogee, and flap angles.
- **flight_plot.png:** A graph showing altitude, prediction, and flap deployment over time.

## Configuration

To change simulation parameters (initial altitude, velocity, target apogee, PID gains), edit the constants and variables in `sitl_main.cpp` or `physics_engine.cpp` before recompiling with `make sitl`.
